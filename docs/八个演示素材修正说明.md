# 八个素材v2与截图提醒修正（2026-11-12）

## 上次哪里检查得不够

上次截图核验只检查了“提取到money等要求”，没有把“套路实验模型分成普通服务、页面仍称不能明确区分”作为失败，导致用户看到矛盾结果。视频只检查画面分数，没有把音轨及声学模块是否一起可用作为验收条件。此前的中文真人/克隆音频确实不同，属于同一说话人同一句话的公开克隆对照；文件和波形摘要不同，听起来相像本来就是克隆目标。不能因此把文件当成同一个，也不能用静音换脸视频展示声音检测。

## 截图现在怎么提醒

本地Qwen提取逐字原话，保留实验分类器原始输出；backend/chat_assessment.py结合明确要求形成解释性提醒。借款＋阻止电话核实，或熟人称呼＋借款＋新账户等组合触发红色“疑似”提醒；普通借款、普通聊天、单独不方便通话不直接判诈骗。程序补充匹配的证据注明来源，模型不可用时标rules_only，不冒充完成语义分析。新增验证码证据限制，转到新账户不能误标为索要验证码。

这是一项证据组合与展示修正，没有声称重训后文字五类准确率超过70%。不把错误分类器的“普通服务”分数当成安全结论；原始分数收在研究记录中。警告依据和原话可核对，不能据此证明身份或定罪。

熟人资金风险展示警方真实案例：汕尾市公安局2023-05-26公开的福州好友视频借款被骗430万元案，链接https://www.shanwei.gov.cn/gdsw110/zwgk/wgk/content/post_924988.html 。已实际查阅原文；标明发布机构、日期及共同风险点，不编造近期新闻，不把用户聊天当作该案原始聊天。普通对话不硬塞该案例。原始截图01仍是虚构功能对照。
