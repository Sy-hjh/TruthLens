# 实际分析方法与本轮修正

| 输入 | 实际算法 | 可核对的输出 | 不具备的能力 |
|---|---|---|---|
| 聊天截图 | RapidOCR提字＋本地Qwen理解要求，逐字原文约束 | 提取原文、对应引用、分类、处理状态 | 不检测文字是不是AI写，不确认身份，不直接判诈骗 |
| 图片 | Smaug视觉编码器与分类层，三个528px视图的logit均值再sigmoid | 三视图分数、汇总分数、强提醒/弱线索边界 | 不可靠识别所有局部P图；视图位置不是修改位置 |
| 视频 | 8个均匀时间点，YuNet人脸优先裁剪，GenD CLIP归一化视觉特征二分类，取均值 | 实际采样时间、逐帧模型输出及阈值 | 不是连续动作、口型同步或人物身份检测；不能覆盖所有生成视频 |
| 音频 | VeriSpoof原生声学模型对真假候选答案计算似然比；8s/4s重叠窗口，阴性XLS-R/AASIST复查中间5s | 窗口时间、各自阈值、分开绘制的两模型分数 | 不用话术判断声音真假；不能凭声确认是谁；不是诈骗概率 |

## 图片误报复现和代价

按用户给定来源标签，本轮实拍0.018737、合成0.997840。实拍三视图约0.0030、0.0004、0.8520，说明模型对裁剪很敏感；不能把第三视图当作局部被修改的证据。旧阈值0.007误报属实，保留在本机私人回归记录。

新策略保留原分数：0.007–0.5为不确定区，0.5及以上才作强模型提醒。不是用两张图训练新分类器，也不把不确定说成真人。已观察634张复核，低区310、不确定23、强提醒301。所有未强提醒均计为合成漏检时，误报0/317、漏检16/317；旧阈值误报12、漏检5，必须同时披露。不是新的独立准确率。

## 文字故障

服务日志证明：OCR已提取文字，Qwen引文跨越换行，严格逐字匹配失败导致整个内容分析不可用。现在仅压缩空白用于定位，再截取原始字符区间显示；不能补字改写。失败会有限重试，仍无有效引文就明确未完成，不说安全。

初版0.6B复测出现错误类别：“撤回一条消息”被列远程要求、“什么案子”被列链接要求。这是失败，不是有效线索。更大本机文本候选必须通过普通聊天、防骗提醒、借款、身份声称和涉案保密等复核后才能启用。没有计算通用文字准确率。

## 图表边界

新增真实推理图，不制造热力图、谱图异常区或所谓伪造位置。图片展示三视图输出；视频仅连采样点，不能推断中间帧；声音两模型分开阈值。没有历史采样数据就提示重新上传，不补造曲线。原始上传仍处理后删除；图表只保留数值、时间和引用，不保存原图片/声纹片段。


## 最终文本候选与实际边界

下载官方Qwen3-1.7B固定版本70d244cc86ccca08cf5af4e1e306ecf908b1ad5e，9个文件含两片safetensors校验后启用，总计约4.08GB。旧0.6B曾给撤回消息乱配类别，更大模型自由抄引文仍曾失败，均保留在本机失败报告。

最终采用原文片段编号选择，程序直接截取真实原文；拒绝不存在的编号和编造引文。10个已观察场景类别覆盖检查完成，包括用户涉案保密、普通聊天、验证码保护、口语借款、屏幕共享和反诈教育。**这不是独立准确率，也没有证明每条短引文单独的语义都充分**：例如模型可能只选“旧卡用不了”作借款背景，故报告可展开实际上下文；仍须人工核对，不把模型类别当事实。没有用这些文字判断声音真假或文字是否AI创作。

实际原记录网页复核中，又过滤了“配合调查”这种不含身份声称的身份类别引文。身份类别必须有可见的自我介绍、角色或称呼依据，不能把普通要求当身份。这是模型后的引文约束，不是替代语义模型的关键词反诈结论。
