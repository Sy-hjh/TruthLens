# 两篇论文读后，亲安具体怎么改

阅读日期：2026-11-11。两份 CAJ 均在本机转换、提取全文并检查核心图表，未上传到外部转换网站。原文件未修改。音频论文67页，风险论文11页。下面页码为转换后PDF页码，括号内为论文印刷页码。

## 先说结论

有用，但不能把论文里的准确率直接贴到亲安。第一篇教我们查模型是不是“看错了特征”；第二篇教我们把“媒体像不像合成”和“对方是否在实施诈骗”分开。它们都不能保证识别所有2026年的克隆声音。

## 1. 海轩：说话人无关特征驱动的克隆音频检测攻防关键技术研究

兰州大学2024年硕士论文，导师刘刚。重点读了方法、实验条件、结果、局限和参考文献。

这里“说话人无关”主要指采样率、背景噪声、开头结尾的静音，不是“已经能认出所有人的声音”。大白话：有的模型学会了“录音比较安静就像AI”，而不是学会真正的合成痕迹。换一个录音环境，实验室成绩就可能失效。

- PDF30–39（22–31）：SiF-Analyzer 检查采样率、噪声和静音对旧检测器的影响。英语FoR、中文MagicData等数据和真实手机转发环境不同。
- PDF53–60（45–52）：SRD-Net 用预训练 WavLM 提取多层声音特征，再由可学习权重和双向LSTM、分类层判断。它分析的是声音本身，不是先转文字再查诈骗词。
- PDF58表5-2：AASIST 原始条件EER为1.13%，去噪2.50%，去静音24.45%。说明“把所有声音先去噪、去静音”未必是好改进。
- PDF60表5-5：SRD-Net 去噪条件EER为0.88%，去静音6.01%。EER越低越好，但不等于今天任意录音的准确率。数据主要是ASVspoof2019，不能代替现代中文克隆测试。

**已经落实：**新增 `check_audio_nuisance.py`，从已观察过的测试录音中取16条（8真人、8克隆），对两类做完全相同的固定条件变化：边缘静音裁剪、音量减半、两端各加0.5秒静音。实际运行后，三种条件各0/16发生判定翻转。结果在 `reports/audio-nuisance-check.json`。这是小规模稳定性检查，不能宣传为抗攻击能力或新独立准确率。

**没有乱改：**没有直接替换为较老的SRD-Net，没有给生产录音统一去静音，没有复现论文的优化规避攻击。现有声学模型仍直接分析波形；以前训练的分类头如果效果不如现用模型，不强行上线。

阅读时也发现写作问题：印刷28页将“假阴性率”和FPR混写，应看FP/(TN+FP)公式；29页“全部增加”与表格中Deep4SNet一行不一致。因此我们保留真实混淆矩阵，不照抄概括性结论。

## 2. 周胜利等：面向AI换脸诈骗的受骗风险识别研究

《数据分析与知识发现》2025年第9卷第11期，DOI：10.11925/infotech.2096-3467.2024.1138。

这篇不是“把文字、图片、声音、视频四个分数平均”。FSFRI使用的是：视频画面、UDP数据包描述、数据包载荷、通信流量时间特征。普通上传网页拿不到微信/QQ通话双方的网络包，不能从一个MP4假装还原这些特征。

- PDF3–5：MobileNetV3提画面特征；CNN提包字节特征；BiLSTM、残差和注意力提通信流量特征；Relief-F、哈希映射与TabNet用于融合分类。
- PDF6–7：实验是QQ、Wireshark、DeepFaceLive构造的模拟场景，10,363条记录，4,508非诈骗、5,855诈骗，5折交叉验证。真实案件用于场景构建，不能写成全部是真实受害者通话。
- PDF8表3：仅人脸特征F1为0.888，四组特征F1为0.920，精确率0.924，召回率0.917。不是我们的网页准确率。
- “噪声比例0.2”是对部分数据记录加高斯扰动，不是录音里混入20%的噪声。

**采用的思路：**两条线分别展示——媒体合成检查回答“画面/声音有没有合成信号”，聊天套路检查回答“对方在提出什么要求、接近什么套路”。真实声音也可能诈骗，AI声音也可以是正常内容。没有带配对标签的训练数据，不把几种模型分数平均成“诈骗概率”。

**没有采用的部分：**网页不抓QQ/微信包，不重建载荷，不声称已实现FSFRI，也不将论文92%的F1当成项目成绩。未来如做实时通信，需要另外设计授权采集与按人物、设备、通话分组的实验，排除设备和协议泄漏。

## 3. 新增文字训练怎么做

下载了作者公开的ScamGen文本数据（2024发布，CC-BY-4.0），包含五类：公检法、理赔退款、取消扣费、熟人关系、普通服务/营销。数据以模板扩充为主，不等于真实老人聊天记录。保留作者更难的Hard划分，不把同一模板扩充内容随机打散来追求漂亮成绩；额外移除跨划分的规范化完全重复文本。

第一版采用字符片段统计和可训练分类器。它确实训练了参数，不是几条固定关键词。训练82,090条，验证7,026条，测试7,486条。测试五分类准确率70.44%，其中普通服务误判明显，因此不能直接交付为可靠诈骗裁决器。严格提醒策略只在验证集选阈值，其余保留不确定：在测试中普通服务误提醒约4.83%，但诈骗类提醒召回仅10.86%。这不能宣传为高性能防骗；它只在折叠详情提供实验提示，原文要求分析继续独立展示。完整混淆矩阵、阈值与覆盖率保留在训练报告，未隐藏失败。

另下载官方中文BERT，比较“冻结中文编码器、只训练分类头”的语义方案。已实际完成：冻结BERT编码器，训练12,000条的分类头，在同样的7,486条Hard测试上准确率65.01%，低于字符基线，因此没有替换网页。结果在 `reports/text-semantic-comparison.json`。这是失败的对比，也保留记录；不代表换个大模型名字就能变准。

也下载了quanshiyun反诈对话数据供后续整理，但它的逐句标签、前缀窗口和同案重复必须先审计，不能把公开train/test文件直接拼起来随机切分。本轮没有把未经审计的数据灌进现用模型。TeleAntiFraud需要申请访问，目前未取得文件；没有绕过权限，也没有写成下载成功。

## 4. 用户能看到的变化

主页面少讲术语，报告展示结果、原文、下一步。话术相似程度与媒体检测分数各自解释；图表来自真实模型输出。技术版本和限制放到展开详情。不会把“没有发现”写成“确定真实”，也不会用真人说了借钱就判AI声音。

说明：五个网页类别是作者五种标签的通俗名称，理赔/扣费等为代表情形，不覆盖所有诈骗类型；这里也没有投资、招聘等独立完整分类。BERT只用了固定SHA顺序选出的12,000条训练样本，因此对比同时改变了特征和样本量，不能据此证明所有语义模型都比字符模型差。
