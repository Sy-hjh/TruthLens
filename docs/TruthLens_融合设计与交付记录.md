# TruthLens 真鉴：融合设计与交付记录

正式名称：**TruthLens真鉴——面向亲友冒充的多模态核验与反诈问答 Web系统**。
项目目录仍沿用 outputs/qinan，避免破坏训练、模型和脚本路径；客户界面、标题、导出文件名、服务描述已换为TruthLens真鉴。

## 两份压缩包怎样融合

| 来源优点 | 最终实现 | 客户视角取舍 |
|---|---|---|
| 包1全幅暖色影像、醒目标题、荧光色重点与留白 | 首页原图、本地字体、深紫与米白统一配色、四个清晰入口 | 保留情感和大气，不把功能按钮散落在画面里 |
| 包1多附件、预览、材料切换 | 最多4份顺序真实核验，逐项预览、移除、报告切换 | 使用真实后端，超限与错误明确提醒 |
| 包2立体拖动、展开反馈 | 按需加载Three.js真鉴透镜，支持拖动与展开、无WebGL时静态替代 | 替换旧亲安字形，避免品牌混用 |
| 包2悬停、光效、按压与页面过渡 | 功能卡片跟随光、悬停抬升、按压反馈、短过渡 | 不让动画阻止操作，支持关闭并尊重系统减少动态设置 |
| 包2偏好、帮助、弹窗 | 大字模式、动效开关、三步帮助、原生模态焦点管理、删除确认与取消 | 手机也能直接找到偏好，不强迫看启动动画 |
| 包2练习、错题反馈、FAQ、进度 | 24题保留；红色错选与绿色正确答案同时标注；会话恢复、重开、键盘选择、常见问题折叠 | 练习情景明确是学习素材，不伪称真实被骗案件 |

## 已移出客户页面

案例试听、两段浏览器朗读的真假对比、演示报告、公开数据对照按钮、模型实验室、模型仓库标识、实验分类器输出、原始帧序号等开发细节。保留用户需要的真实图表、时间片段、截图原话与官方案例引用。

确定为测试的历史记录按明确演示标记或文件名+SHA-256精确匹配归档隐藏，未删除原结果，不按文件名猜测普通用户材料。恢复方式：`python archive_qa_reports.py --restore`。自用验收素材仍留在原目录，网站没有演示素材入口。

## 接线与架构

React + 严格TypeScript + Vite；功能视图按需加载。Three.js独立懒加载，像素比上限1.5，低功耗渲染；隐藏或关闭动态时减少绘制，离开首页释放资源。首页无需等待3D完成即可使用。

- 上传：POST /api/analyze，真实轮询 /api/jobs/{id}，无模拟检测进度百分比。
- 报告、记录、删除：/api/cases及/{id}。
- 聊天校正：/{id}/chat-text；语音校正：/{id}/speech-text，仅重查内容，不改声画分数。
- 问答：POST /api/cases/{id}/agent-events，真实LangChain步骤及最终引用；流中断与兜底明确区分。
- 反馈：POST /api/cases/{id}/feedback，仅供复核，不自动训练。
- 新闻：/api/news，保留来源、发布日期和最近检查时间。

新增report_facts根据真实检测状态解释本次材料，避免所有问题只返回同一套空泛建议；不确认说话人身份，不生成诈骗概率。

## 本轮发现并修复的问题

1. 无关样例与实验输出进入客户界面：移除入口并可逆归档确定的QA记录。
2. 小字对比度不足：实际计算发现3处约3.96:1，调整后手机首页41项平面文字检查无失败。
3. 键盘模式页缺少关联：补齐tab/tabpanel、左右键切换与跳转焦点，修复跳到正文意外改变路由。
4. 视频入口预导入未启用模型，导致慢启动及故障单测等待超时：改为白名单选择当前检测器后再导入。相同公开视频复测分数与之前完全一致。
5. 重负载下内存仅约0.6GB，记录到FCP40秒、INP38秒：保留失败事实；增加闲置缓存预算，不结束其他训练。低内存时释放本项目声音/文字缓存，正在推理的任务不受清理；停止脚本只清理核实身份的本项目子进程。
6. 切换页面导致多份任务只继续一份：核验工作区保持任务生命周期，完成后以非打断提醒呈现，多报告可切换。

## 验证范围与边界

79项后端测试；前端流式分片/断线/错误/参数测试及9项阈值检查；严格类型检查、构建与格式检查。真实浏览器完成视频上传、报告图表、问答、来源、反馈、导出、手机导航、偏好、练习、新闻、键盘及删除取消核验。

八份既有正反样本全部通过回归；用户此前明确标注的一真一假两张旧挑战图也通过本机复测。都是回归，不是新生成器盲测，不能称通用识别率100%。私有挑战图及其原路径不进入源码包。

真实老人试用、不同手机/浏览器实机、更多未知生成器独立评估仍需外部参与和样本，未伪造完成。未录制演示视频，未发布公网。

## 启动与复测

在项目目录双击 start.cmd，浏览器打开 http://127.0.0.1:8010/；已打开的旧页面请Ctrl+F5刷新。
PyCharm打开本项目目录，运行 `python run.py`。实际配置解释器记录在runtime/python-path.txt，当前为D:/software/Python/Python313/python.exe。
手机与电脑连同一WiFi；先停止本项目服务，再执行 `python run.py --host 0.0.0.0`，手机访问电脑WLAN地址的8010端口。仅在可信局域网使用；Windows若拦截，需要允许可信专用网络。不是用WSL或虚拟网卡地址。

前端修改后：`cd web`，`npm ci`，`npm run typecheck`，`npm test`，`npm run format:check`，`npm run build`。运行网站不需要重新训练。

主要新文件：main.tsx负责路由与工作区，LensScene.tsx负责立体透镜，ui.tsx负责图标/弹窗/焦点，AgentReview.tsx负责流式问答和反馈，performance.ts只在本页记录无内容的性能数字，不上传统计。resource_budget.py负责本项目闲置缓存清理。
