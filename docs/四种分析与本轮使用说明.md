# 四种分析，用大白话解释

**不是四个模型都由我们从零训练。现用媒体模型主要是下载作者已训练的模型，我们做本地运行、测试和使用范围调整。**

| 输入 | 它具体干什么 | 本项目训练了什么 |
|---|---|---|
| 图片 | 把图片交给图像模型，检查多个视图里是否存在它学过的生成特征；不是看几个像素就能断定 | 以前训练过小分类头，但现用Smaug是作者预训练模型 |
| 视频 | 定时抽取画面，优先检查人脸，再汇总帧结果；另取声音走声学检测 | 现用GenD画面模型来自作者，不是我们训练的连续动作识别器 |
| 音频 | 直接读声音波形，分段找合成特征；必要时第二个声音模型复查。不靠说话内容判断真假 | 训练过中文克隆分类头，但没有胜过现用方案；现用VeriSpoof-Plus及XLS-R/AASIST来自作者 |
| 聊天截图 | 先OCR读字；训练模型判断接近哪种套路；本地语言模型找对应原话 | 新增ScamGen五类话术分类训练；OCR和Qwen本身来自作者，未由我们从零训练 |

“自己训练”不等于一定更准。用很少样本训练一个头，也不能覆盖今天所有生成器。真实图片误报、AI图片漏报都要如实保留，不能用两个样本调到正确后声称通用了。

## 网页怎么启动

在本项目目录打开PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch.ps1
```

电脑浏览器打开 http://127.0.0.1:8010 。手机访问还需要让服务监听局域网：先运行 `.\stop.cmd`，再运行 `python run.py --host 0.0.0.0`，手机与电脑连接同一Wi-Fi，访问电脑局域网IP加`:8010`。电脑需保持开机，并允许专用网络上的该端口。默认启动仅监听本机，不能直接用手机访问。

## 新的文字模型如何复现

在PyCharm打开本项目根目录，使用已装依赖的Python解释器，在终端运行：

```powershell
python train_text_patterns.py --epochs 12
```

`models/text-patterns/last.npz` 保存训练进度。再次运行相同命令会恢复；要继续到20轮，用`--epochs 20`，意思是总共到20轮，不是再加20轮。Ctrl+C可以结束，最多重做尚未保存的这一轮。这个字符分类器是CPU训练，不用显卡。不要同时运行两份，也不要随意改数据后接旧检查点。

看效果打开 `reports/text-pattern-training.json`。第一版五类准确率约70%，不合格之处已保留，不能宣称90%。多训几轮不保证解决：需要更好的语义特征、更多普通聊天反例以及独立真实截图测试。

语义对比命令：`python compare_text_semantics.py`。它使用官方中文BERT，冻结编码器，只训练分类头；特征缓存允许继续，训练结果在 `reports/text-semantic-comparison.json`，本轮实际结果65.01%，没有超过字符基线，所以没有替换网页模型。下载入口是 `python install_text_encoder.py`，应先等文件校验成功。

## 新增文件各管什么

- `collect_scamgen_text.py`：只从作者公开ZIP读取所需文本，记录来源、CRC和SHA；不运行ZIP里的代码。
- `train_text_patterns.py`：分割审计、字符特征、分类训练、验证选参数、测试并导出安全的JSON/NPZ权重。
- `backend/text_patterns.py`：网页调用训练后的套路分类器，不处理声音。
- `compare_text_semantics.py`：冻结BERT语义特征与分类头对比，不自动上线。
- `install_text_encoder.py`：固定版本下载官方中文BERT并校验。
- `check_audio_nuisance.py`：根据论文补充固定录音条件稳定性测试。
- `docs/论文阅读与改进说明.md`：两篇论文逐项结论、哪些落实、哪些不能照搬。

声音真假、图片真假和诈骗意图不是同一道题。我们分别提供线索，不能给出一个装作精确的总诈骗概率。
