# TruthLens 真鉴：真实用户试用任务单

状态：**尚未实施，由你邀请真实老人试用。不是助手模拟老人，也不是自动测试结果。**
建议每人15—20分钟。记录匿名编号P01、P02即可，不收集姓名、真实电话号码或被骗经历。

准备：先启动电脑网站；如用手机，连接同一可信WiFi并按使用说明开放本项目的局域网监听。只使用本机的练习素材，不进行真实转账，不拨打可疑号码。确认参与者自愿，随时可以停止。

## 主持人规则

读出任务，不指出按钮。第一次操作先不提示，记录时间与是否求助；卡住时可以帮助，但须如实记为“需要帮助”。不要把“他点了按钮”当成“他理解了结果”。

| 任务 | 给参与者的话 | 验收点 |
|---|---|---|
| 1 找到入口 | 请找到检查一份材料的地方。 | 能从首页找到核验工作台 |
| 2 调整阅读 | 如果字太小，请调成大字；如果不喜欢动画，请关闭。 | 能找到偏好，阅读是否更轻松 |
| 3 核验一份视频 | 请上传我们提供的07视频，等待结果。 | 能选择文件，知道正在处理，没有把等待当失败 |
| 4 理解结果 | 这份报告能不能证明视频里的人就是家人？能不能直接决定转账？ | 两问都应回答“不能”，能说出独立回拨 |
| 5 看依据与问答 | 请找到需要注意的时间段，并问问真鉴下一步怎么核实。 | 看懂至少一条图表/原话，能找到真实来源和建议 |
| 6 联系与练习 | 请找到家人联系，再做一道情景题。 | 知道用事先确认的号码，选错后能看懂红色及正确答案文字 |
| 7 管理记录 | 请找到刚才的记录，查看后删除它。 | 能确认要删哪条；知道删除不可恢复，不误删其他记录 |

家人号码可用虚构格式号码作界面练习，**不要真的拨打测试号码**。实际电话按钮只检查它是否进入设备确认界面，是否拨出由参与者自己决定。网站不会自动拨号。

## 怎么反馈给我

只发匿名任务结果、用时、理解回答和卡点；不要发家人真实号码或其他个人信息。我会据此修正界面，再用不同材料安排第二轮，避免只是记住答案。
