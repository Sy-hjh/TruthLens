## 3. 开始自己的训练

```powershell
python train_images.py --epochs 10
```

入口就是根目录的 **train_images.py**。默认读取data/training/manifest.json；输出到models/experiment-head。这个目录已放好本次两轮试训的检查点，直接执行上面命令会从第3轮继续，累计到10轮。

屏幕中epoch表示第几轮，samples表示本轮进度，step表示总更新次数，loss是训练损失。损失下降不等于真实场景更准。验证分数使用6张验证小样本，不能宣传为系统准确率。

## 4. 怎么停止，怎么接着练

在终端按一次 **Ctrl+C**，等待显示Saved再关闭。程序会完成当前批次再保存；每个批次本来就会保存一次。不要反复按停止或直接关机；强制杀进程可能丢当前批次，但上一次完整last.pt仍可续用。

如果PyCharm拦截Ctrl+C，另开一个终端输入：

```powershell
New-Item -ItemType File -Force models/experiment-head/STOP
```

程序在当前批次后停止并消耗STOP标记。随后继续运行同一条命令：

```powershell
python train_images.py --epochs 10
```

它会读取last.pt，继承分类头、AdamW优化器、总步数、本轮位置。不是重新从零开始。

`--epochs 10`表示累计目标10轮；练完10轮后想累计到20轮，改成：

```powershell
python train_images.py --epochs 20
```

默认batch-size=4。续训不要改batch-size或数据清单，程序会检查并拒绝不一致；添加新数据属于新实验，应另选--output，不能混称同一数据实验。

## 7. 到底怎么识别

这套图像实验用视觉Transformer学习图像特征与真/假标签的关系，输出统计分类分数；不是数手指，也不是仅检查透明度或某个像素值。整图AI生成、传统拼接/局部编辑、视频换脸、语音克隆是不同任务，不能把图片训练结果冒充视频或声音效果。

P图沿用TruFor独立异常定位。新图片实验没有替换视频、声音模型，也没有提供视频/声音的新训练入口；这些功能的准确率仍需分别评测，本次没有宣布全部效果达标。
