## 2. 您先按这个顺序检查

1. 首页能看到“本机模型已就绪”。先看大字、按钮和布局是否合您的意。
2. 展开“没有材料？先体验公开对照与模拟”。选择 **案例2 原视频**，再选择 **案例2 换脸对照**。两次都会实际运行模型。
3. **案例1 换脸是刻意保留的漏检回归例**：它确实是公开换脸材料，但本版没有检出。没有把标签当分数回填，也没有把失败样例删掉。案例3可继续对照。
4. 点击“模拟亲人求助”“模拟专家宣传”和“普通内容合成对照”。观察声音、中文转写与表达线索是否分开呈现。
5. 在报告中点击“解释这份报告”。应显示本地Qwen3工作流、实际资料来源与核实建议；模型输出失败时会明确写检索兜底。
6. 打开“联系我的家人”，检查保存与回拨入口。号码只存在当前浏览器，换浏览器或设备需重新保存。
7. 做一道练习题；进入核验记录，检查查看、导出和删除。历史报告是当时版本的结果，不会自动重算；要用新版本检测须重新上传材料。
8. 最后上传您自己的真实材料和已知合成材料比较。不要只测一张，也不要只看低分就认为安全。

公开视频是研究对照，不是您的亲人。声音演示明确为通用合成声音，不是克隆真人身份。

## 5. 以后自己训练，运行哪个

现在**不用为打开网站而继续训练**。先检查网站。需要做新实验时：

### 图片分类头

```powershell
python train_images.py --manifest data/balanced-v1/manifest.json --output models/balanced-v1 --epochs 40 --patience 5
```

`40`是包括已完成轮次在内的目标总轮数，不是每次额外训练40轮。验证不再改善会早停。Ctrl+C后重新运行相同命令和目录即可续训，进度在 `models/balanced-v1/last.pt`；文件占用时会保存在恢复文件中，下次自动读取。

### 视频分类头

```powershell
python train_video_head.py
```

使用已有300段本地素材，冻结VideoMAE编码器，只训练分类头；进度在 `models/video-face-adapt/last.pt`。特征提取阶段中断，会复用已经完成的缓存；分类头阶段每批保存。当前实验已经训练完成并早停，再运行不保证变得更准确。

### 判断是否够了

看未参与训练的真实误报率、合成漏检率、压缩条件和不同生成方法表现，不只看loss或轮数。少量数据反复训练更可能过拟合。新实验不会自动替换网站固定权重，避免边训练边改网页结论。
