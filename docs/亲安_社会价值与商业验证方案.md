# 社会价值与商业验证

亲安面向老人本人收到疑似冒充亲友、机构的视频、语音和截图后的核实需求。材料合成检测和诈骗要求分析分开，联系家人使用事先保存的号码。系统不替老人决定付款。

## 服务模式假设

个人本地体验免费；潜在付费方是社区服务中心、养老服务机构和反诈宣教单位，提供本地设备部署、维护、审核知识更新和使用培训。收费应覆盖设备折旧、运维、人工资料审核和模型评估。暂不设未经验证的价格，不虚构市场份额或客户。

## 本地试点方案

先邀请自愿参与的老人及工作人员使用脱敏演示材料，记录是否能完成上传、理解结果、找到可信联系入口、识别“未检出不等于真实”。不要用真实转账试验。建议至少两轮，每轮改进后使用不同材料，避免记住答案造成虚高。

记录任务完成率、完成用时、理解错误、误触与反馈；分别记录真假媒体误报/漏报、内容风险识别、未知类型失败率、冷/热启动耗时。试点前冻结评价样本与成功条件，再进行测量。不能把精选演示的通过率当作泛化准确率。

## 可持续性

官方材料需保留来源和发布日期，每次更新生成版本SHA并回归检索；新模型候选先跑独立测试，保留原版本和回滚配置。用户反馈仅供复核，未经人工确认的标签不得直接训练。新增API保留运行计数、兜底率与反馈分类，便于分析长期服务成本；不出售个人声音、联系人或聊天数据。

## 当前尚缺

没有实际机构付费验证、老人可用性试验或经审计的防骗金额。社会价值来自明确场景及设计，现实成效需要后续试点数据证明。
