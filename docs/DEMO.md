# 答辩演示顺序

1. 双击start-background.cmd，看到服务已连接。先进入联系家人，保存事先核实的号码。演示使用虚构号码，不实际拨号。
2. 主场景：上传有授权的预录人物视频，查看画面、声音和文字三种独立证据。当前工程视频只证明链路；没有授权假亲人视频时，不用色块视频冒充逼真人脸演示。
3. 展开上传区的“没有材料？体验模拟语音”，点击模拟亲人求助。实际运行声音模型与中文转写，查看转账/阻止核实线索，进入预留联系人。
4. 点击模拟专家宣传，演示冒用权威提示。系统不能仅凭专家一词判定假专家，也不确认具体身份。
5. 点击普通内容合成对照：会检出合成声音，但不命中转账话术。解释合成与诈骗是不同问题。
6. 听错了可以展开校正入口；保留原始识别和修改记录，不改变声音模型分数。
7. 上传已知标签的正常图和编辑图，分别查看整图生成与TruFor定位。保留失败案例，不挑成功样本宣称总体准确率。
8. 听摘要、导出JSON、查看历史、做练习。打印交给浏览器，拨号交给手机确认。

data/demo有三条模拟语音及四条摘要提醒，全部是明确标注的微软通用合成语音，不克隆用户亲人。仅生成素材时联网，日常播放与检测使用本地文件。原先SAPI失败后，本轮补齐独立音频；脚本、哈希、来源见data/demo/source.json。
