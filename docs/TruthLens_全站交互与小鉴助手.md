# TruthLens 全站交互与小鉴助手交付

## 本轮能看到、能操作的新增内容

- 首页增加大型多模态信号观测台，保留照片主视觉、粒子星网和可拖动Three透镜，桌面透镜扩大。
- 核验工作台、报告页：声音/视频/照片/聊天四种导览节点可点选；中心信号、轨道与说明联动。
- 家人联系：保存、回拨、隐私、核实四个主题。
- 反诈课堂：借款、涉案、验证码、共享屏幕四个主题。
- 核验记录：搜索、回看、导出、删除四个主题。节点是功能说明，真正操作仍在下方原功能区域。
- 每个观测台都能拖动滑块旋转视角、展开和收起、暂停和播放光效；遵循全站减少动画。提供选择材料、进入练习、查看记录等快捷按钮，一键跳过导览并把焦点交给真实功能。
- 小鉴机器人全站出现，眨眼、挥手和底部巡游，可以按住拖动换位置；点击打开问答，支持暂停巡游。
- 小鉴问答接真实本地Qwen，不是预设回答动画。读取平台知识库与官方资料检索结果；报告页可选择结合当前报告，经原LangChain报告问答接口回答。
- 遇到付款或验证码问题，明确显示两个可执行的独立核实步骤。

## 关于你提到的“微调过的模型”

当前使用本机已验证的Qwen3-1.7B公开预训练权重，新增的是平台知识库检索、专用提示、结构校验和有来源的兜底。没有进行本平台专属LLM参数微调，界面和实际回答都明确说明这一点。不能把RAG说成微调，也不为做名词展示仓促训练少量模板。独立训练SFT需要合格问答数据、隔离测试集与前后对比，当前不声称已经完成。

## 实测

- 最终87项后端测试通过；前端6个Node用例、严格TypeScript、格式和生产构建通过。
- 浏览器实际点选导览节点、键盘调整视角、展开/收起、暂停/播放、小鉴提问与拖动、课堂和记录导航。
- 1440、390、320宽度未出现水平溢出；联系人页只检查布局，不导出真实号码。
- 减少动画时轨道与机器人动画均为none。小鉴默认在左下方，避免挡住首页右侧透镜展开按钮。
- 发现并修复了手机点击控件时overflow:hidden形成内部滚动、导致导览内容移位的问题，改为overflow:clip，复测内部scrollTop为0。
- 实际模型回答了视频能力、是否微调与付款风险问题。最终HTTP付款问题mode=local_qwen_rag，冷启动约41.88秒；不是所有问题或设备延迟保证。
- 主模型忙时不排队阻塞媒体检测，明确回退平台说明。生成有60秒预算，含模型载入/排队总耗时可能更长。失败绝不假装模型已完成。
- 未改检测权重和阈值，不以新增动效声称识别率提高。没有录制演示视频。

## 你录制或截图时建议的顺序

1. 首页停留，移动鼠标、点击空白光环、拖动透镜。
2. 进入工作台：点选声音、视频节点，拖动“旋转视角”，点击展开。
3. 进入反诈课堂：点选“验证码”“涉案”，往下演示一次错选与解释。
4. 点击左下小鉴，问“视频会检查哪些内容”，展示实际回答；等待结束再录这一段，不能把等待剪成即时性能承诺。
5. 记录页点选“回看”“导出”主题；需要时打开实际报告展示真实图表。

截图不要包含真实联系人号码、私密聊天或原始个人材料。真实检测部分仍需适合来源的正反样本，观测台是交互导览，不是检测证据。
