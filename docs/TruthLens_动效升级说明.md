# TruthLens 动效升级说明

本轮只升级前端交互，检测模型、阈值、上传与报告接口保持原实现。

## 你可以这样体验

1. 首页移动鼠标：粒子连线缓慢漂移，附近粒子避让，背景出现柔和跟随光晕。
2. 点击首页空白区域：出现扩散光环。点击按钮仍执行原功能。
3. 拖动右下角立体透镜、点击加号：保留旋转与展开，增加虚线轨道和三颗绕行光点。
4. 向下探索：功能卡片和内容依次入场；卡片随鼠标轻微倾斜，图标、轨道和箭头响应悬停。
5. 留意标题流光、按钮扫光、点击涟漪、向下箭头呼吸和顶部阅读进度。
6. 使用偏好可以关闭动态效果；也遵循系统减少动画设置。

## 文件

- web/src/ParticleField.tsx：独立Canvas粒子/连线/曲线/点击光环，最多76粒子，窄屏30；绘制上限约30fps，隐藏或离屏暂停绘制。
- web/src/MotionLayer.tsx：滚动进度、入场观察、卡片倾斜、按钮涟漪及清理。
- web/src/LensScene.tsx：Three.js透镜和新轨道光点，仍懒加载。
- web/src/style.css：极光、流光、过渡及减少动画/打印/高对比度适配。
- frontend-next：当前部署构建产物。

## 验证与边界

TypeScript、生产构建、6个既有Node测试通过。浏览器检查1440桌面、390手机，无横向溢出；手机菜单和核验入口正常。关闭动画时标题animation为none、没有隐藏的入场内容；离开首页后Canvas数量为0。曾发现点击光环后立即缩放时半径为负，已修复时间基准与负值钳制，独立新页面复测控制台错误为空。

这些装饰不是检测过程、不是异常热图，不读取上传文件。没有因为加入动画而声称模型更准。约30fps是绘制节流目标，尚未测所有实体设备帧率；Three仍为独立大块懒加载。未录制视频。
