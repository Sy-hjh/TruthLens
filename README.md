# 亲安 · 先核实，再放心

面向老人本人收到的录制视频、语音和图片，分别检查人脸画面、声音合成、整图生成、局部编辑及转写表达，再通过事先保存的号码独立核实。研究辅助版3.0，不确认身份，不作诈骗或付款决定。

**本机使用只看：[现在只看这份.md](现在只看这份.md)。**

## 快速启动

在项目目录双击 `start-background.cmd`，访问 http://127.0.0.1:8010 。停止使用 `stop.cmd`。

开发入口：`python run.py`。这台电脑依赖与权重已准备好，不用先训练。

## 技术结构

React + TypeScript + Vite前端，按需加载视图；FastAPI本机任务编排；X-CLIP与已训练VideoMAE分类头核验人脸时序；XLS-R/AASIST声音检测；Paraformer中文转写；独立图像分类与TruFor局部编辑；BM25资料检索和本地Qwen3受限解释。各模态不拼成一个诈骗概率。

## 真实测试

- 最终300段新来源视频：平衡准确率83.8%，真实误报5/100，换脸漏检55/200。不是所有生成视频准确率。
- 60组中文真人/通用TTS同文本对照：平衡准确率97.5%，真实误报0/60、合成漏检3/60。不是最新声音克隆或老人业务基准。
- 23项自动检查、8份材料真实推理链路、运行服务HTTP上传与版本检查通过。
- 图片泛化仍有明显短板；实测页保留失败实验，未强行发布商品专项模型。演示案例1保留真实漏检结果。

## 复现与换机

本机直接启动。新电脑先运行 `setup.ps1` 建立环境，用该环境的Python运行 `install_release.py` 恢复固定权重与配置；不需要下载全部训练数据。首次恢复需要联网与数GB空间，日常检测不调用付费API。

前端开发：`cd web` 后 `npm ci`、`npm run build`；或根目录 `npm run build --prefix web`。生产结果在 `frontend-next`，后端同源提供页面与API。

测试：`python -m unittest tests test_domain test_advisor test_checkpoint_io -q`；真实权重验收 `python verify_delivery.py`，运行网站的真实HTTP验收 `python verify_deployment.py`。它们使用隔离数据库或仅删除自己创建的测试报告。

文件、训练与截图清单统一见当前使用说明。过程记录见 `docs/CONTINUATION.md`，来源见 `docs/THIRD_PARTY.md`，固定版本见 `release/release.json`。代码中的本地路径、版本与数据用途明确记录，不把旧诊断集当新测试。
